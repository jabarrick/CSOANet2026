# LOSO Cross-Subject Validation

This directory contains the leave-one-subject-out (LOSO) cross-subject validation
experiments for CSOANet2026 and six baseline models, addressing reviewer
comment R1.2 of the CMBBE-IV major revision.

## Contents

```

├── README.md                            ← this file
├── batch_run_loso.py                    ← LOSO runner for CSOANet2026
├── batch_run_loso_baselines.py          ← LOSO runner for the six baselines
├── figure_3_kfold.py                    ← regenerates Fig 3 (5-fold CV box plot)
├── figure_8_loso.py                     ← regenerates Fig 8 (LOSO 3-panel)
├── results/
│   ├── csoa_loso_n46.csv                ← CSOA LOSO per-subject (46 rows)
```

## Reproducing the experiments

### 1. Prerequisites

* Python 3.10
* PyTorch 2.5.1 with CUDA 12.1 (for the deep-learning baselines)
* numpy, pandas, scipy, scikit-learn, matplotlib, mne

```bash
conda create -n eeg_analysis python=3.10
conda activate eeg_analysis
pip install torch==2.5.1+cu121 torchvision==0.20.1+cu121 \
    --index-url https://download.pytorch.org/whl/cu121
pip install numpy pandas scipy scikit-learn matplotlib mne tqdm
```

### 2. Data

The dataset (OpenNeuro ds005697, PerceiveImagine, 46 subjects, 65-channel EEG @
1000 Hz) is publicly available at https://openneuro.org/datasets/ds005697.

The LOSO scripts read pre-computed channel-aligned tensor caches at
`D:/CSOANet_cache_loso/sub_<id>_C65_<hash>.pt` (each ≈ 600 MB; the cache is
generated by the main pipeline at the project root and is not included in this
directory due to size). Override the cache path with `--cache-dir`.

### 3. Running LOSO

For CSOANet2026:

```bash
python batch_run_loso.py
```

For the six baselines (LDA, SVM, RF, EEGNet, ShallowConvNet, DeepConvNet):

```bash
python batch_run_loso_baselines.py --model lda
python batch_run_loso_baselines.py --model svm
python batch_run_loso_baselines.py --model rf
python batch_run_loso_baselines.py --model eegnet
python batch_run_loso_baselines.py --model shallow
python batch_run_loso_baselines.py --model deep
```

Each script writes `eeg_project/results/loso_<model>.csv`. Both scripts accept
`--subjects 01 02 ...` to evaluate a subset of held-out folds; the train pool
always uses all 46 subjects minus the held-out one.

Approximate wall-clock times on RTX 4060 Laptop GPU:

| Model            | Time per fold | 46-fold total |
|------------------|--------------|---------------|
| LDA / SVM / RF   | <1 min       | <1 hr         |
| EEGNet           | ~21 min      | ~16 hr        |
| ShallowConvNet   | ~135 min     | ~100 hr       |
| DeepConvNet      | ~60 min      | ~46 hr (RTX 3090) |

### 4. Regenerating the figures

```bash
python figure_3_kfold.py \
    --csoa-csv    results/kfold_5fold/csoa_5fold.csv \
    --deep-csv    results/kfold_5fold/deep_5fold.csv \
    --shallow-csv results/kfold_5fold/shallow_5fold.csv \
    --eegnet-csv  results/kfold_5fold/eegnet_5fold.csv \
    --ml-csv      results/kfold_5fold/ml_5fold.csv \
    --out         figures/fig3_kfold.png

python figure_8_loso.py \
    --loso-csv    results/csoa_loso_n46.csv \
    --kfold-csv   results/kfold_5fold/csoa_5fold.csv \
    --multi-csv   results/loso_7way_summary.csv \
    --kfold-mean  0.9867 \
    --out         figures/fig8_loso.png
```

## Headline results (N = 46)

| Model           | LOSO mean ± SD       | 5-fold mean ± SD     | parameters |
|-----------------|----------------------|----------------------|------------|
| **CSOANet2026** | **0.9673 ± 0.0631**  | 0.9867 ± 0.0247      | **3,028**  |
| DeepConvNet     | 0.9791 ± 0.0492      | 0.9472 ± 0.0596      | 319,327    |
| ShallowConvNet  | 0.9688 ± 0.0637      | 0.9824 ± 0.0322      | 123,242    |
| EEGNet          | 0.9616 ± 0.0490      | 0.9825 ± 0.0273      | 8,874      |
| RF              | 0.9029 ± 0.1130      | 0.9748 ± 0.0319      | —          |
| SVM             | 0.8947 ± 0.1143      | 0.9714 ± 0.0282      | —          |
| LDA             | 0.8645 ± 0.1221      | 0.8577 ± 0.0689      | —          |

Wilcoxon paired CSOANet2026 vs each baseline (N = 46): vs LDA p = 6.0e−9,
vs SVM p = 5.8e−8, vs RF p = 1.4e−7, vs EEGNet p = 2.7e−3, vs ShallowConvNet
p = 0.41 (not significant), vs DeepConvNet p = 6.6e−3 (DeepConvNet wins).

CSOANet2026 reaches near-DeepConvNet stability and accuracy at roughly 1/105
of its parameter count (3,028 vs 319,327), 1/40 of ShallowConvNet's (3,028 vs
123,242), and 1/3 of EEGNet's (3,028 vs 8,874).
