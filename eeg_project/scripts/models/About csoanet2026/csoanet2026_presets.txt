  CSOANet2026 — 20 BCI Task Presets (Copy-Paste Ready)
===========================================================

HOW TO USE:
  1. Find the preset matching your task below.
  2. Copy the single TASK = ... line.
  3. Paste it to replace the TASK line in csoanet2026.py.
  4. Done. The model auto-adapts to your data.

FORMAT:
  TASK = auto_cfg(channels, timepoints, n_classes)

===========================================================
  NOTES
===========================================================

- All presets use auto_cfg() which computes optimal F1, D, dropout,
  kernel sizes, dilation rates, and pool factors automatically.
- For custom tasks not listed above, simply call:
    TASK = auto_cfg(your_channels, your_timepoints, your_n_classes)
- The model adapts to ANY channel count (1–256), ANY sampling
  rate / epoch length, and ANY number of classes (2–40+).
- For tasks with > 12 classes, the model auto-scales to F1=32, D=4
  for additional capacity.
