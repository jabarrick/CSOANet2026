# CSOANet2026 Figure Generator

Single-file Python script that generates all figures (Fig. 3–7 main + Fig. S1–S12 supplementary) for the CSOANet2026 manuscript.

Each figure is saved as a single **PNG** at 300 DPI under `eeg_project/figures/`.

---

## Requirements

- Python ≥ 3.10
- Conda environment `eeg_analysis` with:
  - `torch`, `numpy`, `pandas`, `scipy`, `scikit-learn`
  - `matplotlib`, `seaborn`
  - `mne` ≥ 1.5
- GPU optional (CUDA accelerates the training-based groups by ~3×)

All preprocessed data and CSV result files must exist under `eeg_project/` before running.

---

## Quick Start

```powershell
conda activate eeg_analysis

# Generate all figures (~35 min)
python generate_figures.py

# Or generate only fast figures (~2 min)
python generate_figures.py --group results
```

Output appears under `eeg_project/figures/` as `.png` files.

| Group | Figures | Runtime | Requires |

## Command-Line Usage

### Run All Figures

```powershell
python generate_figures.py
```

Runs all 4 groups with default subjects (04, 10, 22).

### Run Specific Figures

```powershell
python generate_figures.py --fig 3                    # just Fig. 3
python generate_figures.py --fig 3 6 7 S8             # several at once
python generate_figures.py --fig S1 S2 S3 S4          # supplementary only
```

### Customize Subjects

Per-subject figures default to Sub-04 (high performer), Sub-10 (BCI illiteracy), Sub-22 (model advancement):

```powershell
python generate_figures.py --fig 5 --subjects 04 10
python generate_figures.py --group neuro --subjects 04 10 22 31 47
```

> **Note:** Fig. 5 always compares exactly 2 subjects (high vs low performer). If you pass more, only the first 2 are used.

## CSV File Format

Per-model CSVs:

**`csoanet2026_all_subjects.csv`**, `shallow_all_subjects.csv`, `deep_all_subjects.csv`:
```csv
subject,acc_mean,acc_std
01,0.9501,0.0152
```

**`eegnet_all_subjects.csv`**: `subject,cv_eegnet`
**`ml_all_subjects.csv`**: `subject,cv_lda,cv_svm,cv_rf`
**`demographics.csv`**: `subject,age,sex` (auto-built from BIDS `participants.tsv`)

## Troubleshooting

- **"No results" on startup**: check CWD and CSV filenames
- **`ModuleNotFoundError`**: `conda activate eeg_analysis`
- **CUDA OOM**: `set CUDA_VISIBLE_DEVICES=` to force CPU
- **Fig. S4 skipped**: need `participants.tsv` in `eeg_project/data/raw/ds*/`
- **Fig. 5 blank**: pass exactly 2 subjects: `--subjects 04 10`

## Inserting Figures into Word

Use **Insert → Pictures → This Device** (not drag-drop) to embed rather than link.

For TIF/PDF submission, re-enable PDF/TIF export by editing `save_fig()` or convert via GIMP/ImageMagick.
